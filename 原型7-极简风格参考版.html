Access Control

详情页只对登录用户开放。

平台首页、列表页、搜索页可以公开展示；一旦进入 Agent 详情、Skill 详情、微调任务详情或个人中心，就必须完成登录鉴权。 这让内容曝光与后台能力天然分层。

1
前端路由守卫：未登录访问详情页时自动跳转登录页，并带回跳地址。
2
后端 JWT 兜底：详情接口本身开启鉴权，不依赖前端拦截。
3
后台 RBAC：创建、更新、导入、删除等操作只对有权限的角色开放。
API Key / Self Skill

平台自身也是一个可调用的 Skill。

用户登录后可在右上角生成 API Key，进入专门的 API Key 页面查看权限范围、最后使用时间与调用示例。 之后把平台自管理 Skill 引入 AI Agent，就能直接查询 Skills 列表、导入、远程添加和下载。

A
Scopes：`skills:read`、`skills:import`、`skills:write`、`skills:download`、`admin:manage`。
B
安全基线：明文 Key 只展示一次，数据库仅保存哈希值，并保留调用审计。
AI Agent 可直接调用的管理能力示意： list_skills() import_skill(file) add_remote_skill(url) download_skill(skill_id) upsert_skill_metadata(payload)
One Flow

从浏览，到授权，到被 AI Agent 接管后台，只需要四步。

Step 01

浏览市场

用户先在公开列表中筛选 Agents、Skills 与模型入口，确认需要深入查看的目标。

Step 02

登录查看详情

进入详情页时触发登录，解锁完整文档、下载、导入、收藏与后台操作入口。

Step 03

生成 API Key

在右上角或个人中心创建带 Scope 的 API Key，用于外部 Agent 安全调用。

Step 04

自然语言管理

在 AI Agent 中引用平台自带 Skill，直接执行查询、导入、同步与下载操作。
